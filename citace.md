# Citace a zdroje

## Zadání a technické informace

- CS50's Web Programming with Python and JavaScript, Project 0: Search. Specifikace textového, obrázkového a rozšířeného vyhledávání: <https://cs50.harvard.edu/web/projects/0/search/> (navštíveno 22. 10. 2026).
- HTML Standard, WHATWG. Použité sémantické prvky a typy formulářových polí: <https://html.spec.whatwg.org/> (navštíveno 22. 10. 2026).
- Google Search. Cílové adresy vyhledávacích formulářů: <https://www.google.com/search> (navštíveno 22. 10. 2026).
- Nu Html Checker a W3C CSS Validation Service: <https://validator.w3.org/nu/> a <https://jigsaw.w3.org/css-validator/> (navštíveno 22. 10. 2026).

## Použité prompty

- „Vytvořte na GitHubu nový repozitář googlesearch; vytvořte web dle zadání CS50 Search, přidejte stránku s ukázkami formulářových prvků, validátory HTML/CSS, citace a odkaz na portfolio; řešení publikujte přes GitHub Pages.“
- „Na všech stránkách projektu budou odkazy na validaci HTML a CSS a na soubor s citacemi a zdroji. Nefunkční formuláře označte.“

## Poznámka k autorství

Kód HTML a CSS byl vytvořen s pomocí AI podle výše uvedeného zadání. Projekt je samostatnou implementací; nepoužívá stažené obrázky, externí fonty ani cizí zdrojový kód.
